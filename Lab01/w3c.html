¿Qué es el W3C?

El World Wide Web Consortium (W3C) es la organización que desarrolla estándares para la web, como HTML, CSS y XML.

HTML5

HTML5 es la quinta revisión del lenguaje HTML. Introduce etiquetas semánticas como <header>, <nav>, <main>, <article> y <footer>, mejorando la accesibilidad y el SEO.
